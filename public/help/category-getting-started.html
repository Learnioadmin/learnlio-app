Create a parent account and add a child

Create your parent login first. From the dashboard, choose Add child and follow the steps.

You can add more children later. Each child gets their own learning space and progress.

Still stuck? Visit Contact or email hello@learnlio.co.uk.

Parent login vs child access

Parents manage billing, Parent Insight, and settings. Children use Lessons and Tutor in a calm, guided flow.

If Child Mode is on, parent areas ask for an unlock.

Still stuck? Visit Contact or email hello@learnlio.co.uk.

What Learnlio is (and is not)

Learnlio is a calm learning support tool for UK children. It helps practise Maths and English in small, gentle steps.

It is not a diagnosis and it does not replace school support.

Still stuck? Visit Contact or email hello@learnlio.co.uk.

How XP and rewards work

XP is effort-based, so steady practice builds confidence. Total XP grows across Tutor and Lessons.

Rewards unlock as total XP grows. It is designed to encourage short, calm sessions.

Still stuck? Visit Contact or email hello@learnlio.co.uk.

Change a child\'s starting point

The setup check helps set a gentle starting point. You can retake it to adjust the baseline.

This keeps lessons at a comfortable level and avoids pressure.

Still stuck? Visit Contact or email hello@learnlio.co.uk.
